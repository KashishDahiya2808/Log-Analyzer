# Log Analyzer

A Python-based Log Analyzer that helps detect suspicious activities from log files.

## Features
- Detect failed login attempts
- Identify suspicious IP addresses
- Generate security reports

## Technologies Used
- Python
- Regex
- File Handling
- Collections Module

## How to Run

```bash
python analyzer.py


## Sample Output

```text

Total Failed Logins: 6

Failed Login Attempts by IP:
192.168.1.10 --> 5 attempts
192.168.1.30 --> 1 attempts

Suspicious IP Addresses:
192.168.1.10 (Suspicious - 5 failed attempts)
